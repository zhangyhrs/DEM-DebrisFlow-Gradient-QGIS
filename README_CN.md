# 泥石流纵比降计算 QGIS 插件

[英文版说明](README.md)

用于基于数字高程模型快速计算泥石流主沟道纵比降的 QGIS 插件。

## 一、主要功能

插件提供两种计算方式：

1. **数字高程模型 + 泥石流流域面**：已有流域边界时，以每个流域面作为独立计算单元，自动提取主沟道并计算纵比降。
2. **数字高程模型 + 泥石流沟口点**：没有流域面时，根据沟口点进行沟口吸附，自动划分汇水流域，再提取主沟道并计算纵比降。

核心流程：

`数字高程模型 → 洼地填充 → D8 流向 → 汇流累积 → 沟口确定或吸附 → 流域提取 → 主沟道追踪 → 高差 → 沟长 → 纵比降`

纵比降计算公式：

`纵比降（‰）=（沟顶高程－沟口高程）÷ 主沟道长度 × 1000`

## 二、方法来源与参考文献

本插件的总体技术思路参考了张肃《基于 DEM 的泥石流流域纵比降的快速计算方法》。该文提出基于数字高程模型水文分析自动提取泥石流主沟道，并根据沟顶、沟口高程差和主沟道长度快速计算泥石流纵比降。

论文原始流程以**已有泥石流流域范围**为前提，在每个流域范围内提取河网并确定主沟道。插件中的“数字高程模型 + 流域面”模式与这一思路一致；在此基础上，本插件进一步增加了“数字高程模型 + 沟口点自动划分流域”模式，用于没有现成流域面的情况。

参考文献：

> 张肃. 基于 DEM 的泥石流流域纵比降的快速计算方法[J]. 2018(09): 238-239.

本插件为独立的软件实现与功能扩展，论文仅作为算法与技术路线参考。

## 三、输入数据

- 数字高程模型栅格；
- 方式一：泥石流流域面；
- 方式二：泥石流沟口点，建议设置唯一编号字段。

建议数字高程模型和矢量数据采用以米为单位的投影坐标系，以保证沟长、搜索距离等计算具有明确的实际单位。

## 四、主要参数

- **最小汇流面积**：控制主沟道追踪时的最小汇流规模，默认 0.01 平方千米；
- **流域搜索半径**：方式二中以沟口为中心进行数字高程模型水文分析的最大搜索范围；
- **沟口吸附半径**：将人工沟口点吸附到附近汇流累积量较大的栅格像元，单位为像元。

## 五、输出结果

两种方式均输出主沟道和统计表；方式二另外输出自动划分的流域面。

矢量格式支持：

- GeoPackage
- Shapefile
- GeoJSON

主要属性字段采用中文短字段名：**流域号、面积、沟顶高、沟口高、高差、沟长、纵比降、汇流数**。

## 六、使用建议

自动划分流域和主沟道属于数字高程模型水文分析结果，实际应用时应结合影像、等高线和已知沟谷位置进行检查。对于工程评价、灾害评估等专业应用，不建议直接以自动计算结果替代必要的人工复核。

## 七、安装

正式发布后可在 QGIS 插件管理器中搜索 **DEM Debris Flow Gradient** 安装。

也可下载正式发布包 `DEM_DebrisFlow_Gradient_v1.0.0.zip`，在 **插件 → 管理并安装插件 → 从 ZIP 文件安装** 中安装。

> 不要使用 GitHub 页面中的“下载源代码压缩包”作为 QGIS 安装包，应使用正式发布页面提供的插件压缩包。
