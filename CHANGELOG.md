# Changelog

## 1.0.0

- First stable public release.
- Supports DEM + watershed polygon mode.
- Supports DEM + outlet point automatic watershed delineation mode.
- Calculates watershed area, top elevation, outlet elevation, relief, main-channel length, longitudinal gradient and outlet flow accumulation.
- Supports GeoPackage, Shapefile and GeoJSON vector outputs.
- Uses Chinese result field names for GIS attribute tables.
- Added publication-ready metadata, icon, documentation and GPL license.
